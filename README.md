
# Segmentation Task 2

This repository contains another segmentation task focusing on data processing, visualization, model evaluation, and prediction using deep learning techniques.

## Features
- Data processing and visualization using Python libraries.
- Model training, evaluation, and prediction using TensorFlow and Keras.
- A practical approach to deep learning tasks for segmentation.

## How to Use
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/FruitRecognition.git
   ```
2. Navigate to the project directory:
   ```bash
   cd FruitRecognition
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the Jupyter Notebook:
   ```bash
   jupyter notebook notebooks/FruitRecognition.ipynb
   ```

## Interactive Notebook
[Run on Google Colab](https://colab.research.google.com)

- glob, os, keras, cv2, pandas, matplotlib, IPython, google, numpy, tensorflow
